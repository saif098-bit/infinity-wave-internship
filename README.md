# Infinity Wave Internship

This repository contains the work completed during my internship at Infinity Wave Inc, covering both machine learning pipeline workshops and hands-on computer vision data annotation for a real-world project.

## About

The internship combines structured workshops on the end-to-end machine learning pipeline (data preprocessing → training → validation → testing) with practical, on-the-job data annotation work for Infinity Wave's cricket computer vision project.

## Projects

| Project | Description | Link |
|---|---|---|
| Heart Disease Prediction | ML pipeline workshop project — predicts heart disease from patient data using SVM (91.3% test accuracy) | [`heart-disease-prediction/`](./heart-disease-prediction) |
| Data Annotation (Cricket CV) | Real-world data annotation work using CVAT — pitch, stump, bowler, and batsman labeling for a computer vision training dataset | [`data-annotation/`](./data-annotation) |

## Tech Stack

Python, pandas, NumPy, scikit-learn, matplotlib, seaborn, CVAT

## About Each Folder

Each project folder contains its own README with detailed methodology, results, and (where applicable) supporting files such as notebooks, requirements, or weekly reports.
